## Goal
`redux/design/brief.md` is the one guide we build from: every design decision in Juxtopposed's video with its
reason, its milestone, and the video moment, frame and Figma node that show it. No detail shown only in the video is
missed.

## Scope (what's left)
Steps 1–6 below, then Verification. Frames and the video stay out of git (`redux/design/source/` is ignored).
`frame-picks.tsv` is committed, so anyone with the video regenerates the exact same frames.

### 1. Put the video in place
Save the video as `redux/design/source/video.mp4`. If you don't have it yet:
```bash
podman run --rm --entrypoint sh -v "$PWD/redux/design/source:/out" localhost/vlc-redux-transcriber:latest \
  -c 'yt-dlp -f "bv*[height<=1080][ext=mp4]+ba[ext=m4a]/b[height<=1080]" --merge-output-format mp4 -o /out/video.mp4 https://youtu.be/ERFeOgqk324'
```
Expect about 20:30 at 1920×1080.

### 2. Make the contact sheets
```bash
redux/dev.sh run redux/tools/video-sheets.sh
```
Expect about 615 frames, 39 sheets (`sheet-<startsec>-<endsec>.jpg`, 32 s each) and a few hundred scene cuts in
`redux/design/source/video-work/`.

### 3. Review every sheet: 4 agents in parallel
Start four `general-purpose` agents in one message, one per segment:

| Agent | Sheets (by start second) | Transcript sections |
|---|---|---|
| A | 0000–0288 (0:00–5:20) | 1–4 |
| B | 0320–0608 (5:20–10:40) | 5–6 |
| C | 0640–0896 (10:40–15:28); skim the sponsor 14:03–14:50 for UI only | 6–11 |
| D | 0928–end (15:28–20:30) | 12–14 |

Prompt for each agent (fill in the segment):
> You're reviewing frames of Juxtopposed's VLC redesign video for the VLC Redux project. Read
> `redux/design/brief.md` and transcript sections <N–M> in `redux/design/transcript.md`. Then open EVERY contact sheet
> in `redux/design/source/video-work/sheets/` whose start second is in <range>, in order; each tile is labelled mm:ss.
> Also read `redux/design/source/video-work/scenes.tsv` for that range.
> - **Text too small?** Pull the full-resolution frame with
>   `redux/dev.sh run ffmpeg -nostdin -v error -ss <sec> -i redux/design/source/video.mp4 -frames:v 1 -y build/peek-<agent letter>.png`
>   and read that file.
>
> Report every moment that shows design information:
> - the new UI
> - old-VLC "before" states that the design fixes
> - menus, dialogs, hover and animation states
> - exact labels and option names
> - layouts that differ from what the brief says
>
> For each moment, return a row: `time | what is visible (labels, layout, states) | brief entry it supports or "NEW" | suggested slug | crop WxH+X+Y in 1920×1080 if a close-up helps | gap IDs it informs (see redux/milestones/GAPS.md) | differs from Figma? (name the node from redux/design/screen-map.md)`.
>
> Also list the brief `?t=` times in your range that are wrong, each with the correct time. Don't edit files.

### 4. Pick the frames
- **Target 40–60 rows** in `redux/design/frame-picks.tsv` (time, slug, caption ≤ 12 words, optional crop).
- **Coverage:** every brief entry the video shows gets at least one frame.
  - Add **before/after pairs** where the old VLC state explains the decision (subtitle menus, Open Media dialog, settings, Customize).
  - Add **close-up crops** for details: cone volume, thick seek bar, waveform bar, top-bar folder name, subtitle timeline, the four sidebar tabs, filter previews with presets, sort menu (Unwatched/Watched first), Add Subtitles dialog, OSD with key, onboarding shortcuts screen, alternate Customize layout.
- **Slugs** are kebab-case nouns: `sidebar-subtitles-tab`, `volume-cone-closeup`.
- Run `redux/dev.sh run redux/tools/video-frames.sh`, then **open every extracted frame yourself** and fix any caption or crop that's off. Re-run until all are right.

### 5. Finish the brief
- **Fix times:** correct every `?t=` link to the real moment, using the agents' corrections. Fix the transcript section times if they're off; the checker uses them.
- **Cite frames:** add the frame file names to each entry's Refs line, e.g. ``Refs: [07:05](…?t=425) · `0705-sidebar-subtitles-tab.jpg` · Figma 3180:17989``.
- **Add new entries** for details the agents marked "NEW", in the right track section.
- **Video vs Figma:** replace the placeholder with a table `Item | Video shows | Figma shows | Build from`. The rule is Figma for visuals and the video for behavior, unless a row says otherwise.
- **Frames:** replace the placeholder with:
  - where the frames live (`redux/design/source/video-frames/`, regenerate with `video-frames.sh`)
  - a table `Frame | Time | Shows | Used in`, built from `video-frames/index.tsv`
- **Shrink `PLAN.md` §2a** if it still repeats the brief; it should be a pointer only.

### 6. Update the gaps
In `redux/milestones/GAPS.md`:
- Add a Resolution-log row for every gap the frames settle, citing frame and time. Likely: G3, G4, G7, G8, G10, G13, G16, G19.
- Add new gaps with the next free G-numbers.
- Add a `DECISIONS.md` entry if an answer changes a milestone's plan.
