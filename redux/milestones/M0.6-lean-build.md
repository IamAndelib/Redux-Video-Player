## Goal
The app is built from only what `SCOPE.md` keeps, and a repeatable test proves it still plays every format in scope.

## Research
- **How to cut:** VLC's module loop (`modules/meson.build`) already supports `enabled: false` per module, and
  `test/meson.build` skips tests whose plugins are disabled. Feeding that flag from one list covers plugins with and
  without build options, with a two-hunk upstream touch (D20). `--auto-features=disabled` was rejected: option-less
  plugins (http, udp, ftp, all of `stream_out/`) would still build.
- **Prior art for test media (adopted):** FFmpeg's FATE suite, the reference sample collection FFmpeg tests
  against, covers what can't be synthesized (VC-1, PGS, VobSub, DVB/ARIB subtitles, TrueHD Atmos, DTS-HD MA, Dolby
  Vision, HDR10+, MXF, RealMedia, WTV). 28 samples are pinned by sha256 in `redux/tools/samples.tsv` and credited in
  `redux/CREDITS.md`. Everything else is synthesized with the container's FFmpeg 9.
- **Pitfalls found:** the dummy audio output accepts AC-3/E-AC-3/DTS/TrueHD as passthrough, which hides decoding,
  so those files are replayed with FFmpeg's decoder preferred; VA-API's "profile not supported" probe (no AV1
  hardware on UHD 620) is not a failure, dav1d decodes in software.
- New gaps: G22 mostly resolved (only RAR is left); G23 (code.videolan.org downloads stall) was found earlier.

## Decisions
- D20 (cut by name through VLC's `enabled` flag).
- End of playback (maintainer feedback): when nothing comes next, VLC's `play-and-pause` is switched on so the last
  video pauses on its final frame and the player stays open; a queue still advances. Set in the playlist
  controller's has-next callback (`modules/gui/qt/playlist/playlist_controller.cpp`); the user's own "pause after
  every item" setting wins. Model: mpv's keep-open (credited).
- Play after the end restarts the video (maintainer feedback, D21): a small player-core change, so Space, media keys
  and MPRIS behave like the button; a seek in between resumes from the seek position. Upstreamable.
