# M0.7: Flatpak skeleton

- **Track / size:** A / M
- **Branch:** `m/M0.7-flatpak`
- **Issue / PR:** [#46](https://github.com/IamAndelib/Redux-Video-Player/issues/46) / the M0.7 PR
- **Depends on:** M0.6 (lean build, codec matrix)

## Goal
Redux Video Player installs and runs as a Flatpak on the maintainer's desktop, and the codec/format matrix passes
inside the sandbox.

## Research
- **Prior art (adopted, credited in `redux/CREDITS.md`):** no finished VLC 4 Flatpak exists, and none builds with
  meson. We combine:
  - Flathub `org.videolan.VLC` (branch `mv/test-alpha`, a VLC 4 test) for the module set and plugin-cache step
  - VLC MR !10454 for the patch-free cache trick (fixed plugin mtimes, then `vlc-cache-gen`)
  - Flathub `io.mpv.Mpv` for the FFmpeg n9.0.1, libplacebo v7.360.1 and libass 0.17.5 blocks (tags verified against
    their commits)
  - Flathub `org.kde.haruna` for the permission set
  - Not usable: MR !10454 needs network during the build (contribs), which Flathub forbids.
- **Runtime:** KDE 6.11 = Qt 6.11.2, the same Qt as the dev container. It ships Qt's private headers (VLC's Wayland
  compositor needs them), KF6WindowSystem, shaderc, Vulkan, libva, dav1d 1.5.1, taglib 2.1.1, libarchive, mpg123.
- **Bundled:** FFmpeg (decoders only, D15), libplacebo, libass, libdvbpsi 1.3.3, utfcpp (libebml would otherwise
  download it mid-build), libebml 1.4.7, libmatroska 1.7.2, medialibrary 0.13.2. Same versions the dev build links.
- **Not bundled yet (niche formats, added only if the matrix needs them):** faad2 (FFmpeg decodes AAC), libvpx
  (FFmpeg decodes VP8/VP9), zvbi, libmodplug, game-music-emu, sidplay2, fluidsynth, kate, spatialaudio,
  libebur128, soxr.
- **VLC's meson build installs no desktop file, metainfo or icons:** they live in `redux/packaging/`.
- **Found while building (fixed):**
  - VLC master needs meson ≥ 1.10; the KDE 6.11 SDK has 1.9.2. A build-only `meson` module (1.12.1, the dev
    container's version) runs from its source tree and is removed from the app.
  - `-Dstream_outputs=false` requires `-Dvideolan_manager=false` (VLM is cut anyway); the dev `build.sh` now sets
    both too, so the two builds stay identical (D20).
  - Qt lives in `/usr/include` in the KDE SDK; pkg-config drops that "system" dir, and `moc` then fails with
    "Undefined interface". `PKG_CONFIG_ALLOW_SYSTEM_CFLAGS=1` for the VLC module fixes it.
  - Turning stream outputs off (needed for the VLM fix) exposed three upstream bugs, fixed with D24.
  - The FATE ARIB sample failed without `aribb24`, so that one library was added (KISS: no other niche library
    was needed).
- New gaps: G24 (medialibrary test crashes at exit), G25 (a player test times out under load). G23 (code.videolan.org) did not recur for the Flatpak sources, but `git fetch upstream` stalled again.

## Scope
- `redux/packaging/`: manifest, `build-vlc.sh` (reads `redux/cut-modules.txt`), desktop file, metainfo, placeholder
  icon.
- `redux/tools/flatpak.sh` (build, run, lint, matrix); `play-matrix.sh` accepts `VLC_CMD`.
- D22 (host Builder exception).

## Out of scope
- Flathub submission, final icon and name review (M10.1, M10.3); network permission for subtitle search (M5.7).

## Acceptance criteria
- [x] `redux/tools/flatpak.sh build` builds and installs the app (0.0.1, KDE 6.11 runtime, VLC 4.0.0-dev)
- [x] The codec/format matrix passes inside the Flatpak: 79 of 79
- [x] VA-API decodes on the maintainer's GPU inside the Flatpak (Intel iHD), and libplacebo tone-maps HDR
- [x] desktop file and metainfo validate; the linter's three findings are all explained (below)
- [ ] The maintainer opens "Redux Video Player" from the app menu and plays their files (checklist below)

## Manual checklist (for the maintainer)
1. [ ] **Open:** your app menu → "Redux Video Player" (the Flatpak, no "(dev)") · **Do:** start it · **Expect:** the
   usual Home page opens with no error dialog.
2. [ ] **Open:** the Flatpak · **Do:** Media → Open File → one of your own videos (≥ 30 s), once from your home
   folder and once from another drive if you have one · **Expect:** it plays with sound; the file dialog can browse
   everywhere.
3. [ ] **Open:** the Flatpak · **Do:** play a 4K or HEVC/10-bit video of your own · **Expect:** smooth playback
   (hardware decoding is on in the sandbox).
4. [ ] **Open:** the Flatpak · **Do:** Media → Open File → `VLC-Redux/build/media/Videos/Clips/subtitles-ass-demo.mkv`
   (60 s) · **Expect:** styled subtitles show; at the end the last frame stays; pressing Play restarts from 0:00.
5. [ ] **Open:** the Flatpak while a video plays · **Do:** use your keyboard's media keys or the KDE media
   applet · **Expect:** play/pause works and the applet shows the video's title.
6. [ ] **Open:** the Flatpak · **Do:** quit with Ctrl+Q · **Expect:** it closes cleanly; no crash dialog (G24).
7. [ ] **Open:** "Redux Video Player (dev)" (regression: the dev build now also builds without stream outputs)
   · **Do:** play a video of your own · **Expect:** same as before.
8. [ ] **Open:** the [GitHub issues](https://github.com/IamAndelib/Redux-Video-Player/issues) and
   `.github/CONTRIBUTING.md` on the PR branch · **Do:** read it as your collaborator would · **Expect:** it says how
   to set up, find, claim and hand over work; Q0.1–Q0.7 (#56–#62) and the gap issues (#63–#66) exist.

**Known not working yet:** the UI is still stock VLC (the redesign starts at M1.1); cut features still have menu
entries (M0.8); the icon is a placeholder (M10.1); snapshots can't be saved from the Flatpak because your files are
read-only to it (M4.1 adds a writable Pictures folder); not on Flathub yet (M10.3).

**Report:** the item number and what you saw (a screenshot helps).
