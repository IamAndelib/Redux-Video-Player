## Goal
The agent QA loop of QA.md, made concrete. It covers:
- roles and rubrics: visual against Figma and the brief, UX and accessibility, playback and formats, regressions
- a findings format with severity, evidence and the suspected file
- the loop itself: generate, run, triage, fix, re-run, with a round cap; unresolved items go to `GAPS.md`
- a per-PR QA report

Acceptance (ROADMAP): a dry run on a seeded bug finds, fixes and re-tests it.
