## Research
- **Upstream:** VLC's `debian-meson` CI job uses a prebuilt image, `meson test` under gdb, JUnit output. Nothing on
  GitHub builds VLC 4 in a custom container (T1a).
- **Blocker found (T1a, verified):** `bin/vlc.c` refuses to run as root unless built with `run_as_root`, and GitHub's
  `container:` jobs run as root. Locally `redux/dev.sh` runs as the user via Podman `--userns=keep-id`.
  → **Run Podman on the runner and reuse `redux/dev.sh`** (T1a R2): CI runs exactly what we run locally, non-root,
  instead of a second CI-only way of running things (T1a R1, which GitHub calls unsupported as non-root).
- **Image:** tag it with a hash of `.devcontainer/`; pull it from GHCR, or build it with `dev.sh image` and push it
  (main only) on a miss. A PR that changes the Containerfile builds its own image automatically. Layers stay out of
  the 10 GB Actions cache, which ccache needs (T1a).
- **ccache:** `actions/cache` restore/save with a run-ID key and prefix fallback, saved on main only, as mpv does.
  PR jobs never download medialibrary (it's in the image), so G23 only affects image builds (T1a).
- **Flatpak (T1b):** `flatpak/flatpak-github-actions` v6.8, MIT (the `flathub-infra` one the issue names is archived
  since 2025-04), in `ghcr.io/flathub-infra/flatpak-github-actions:kde-6.11` (`--privileged`). Its default build and
  repo dirs would be copied into the build by our `dir` source; put them under `build/` (already skipped). A cache key
  of `flatpak-builder-x86_64-${{ github.sha }}` refreshes the state cache. It neither installs nor lints.
- **Matrix in the Flatpak:** `play-matrix.sh` needs `ffprobe`, `timeout` and `column`; the kde container has no
  `ffprobe` and runs as root (VLC refuses). → a third job on a plain runner as the normal user: `apt install flatpak
  ffmpeg`, install the bundle (pulls the KDE runtime from Flathub), `flatpak.sh matrix` with `build/matrix` from the
  `qa` job. No player I found runs playback tests on its built Flatpak in CI; Bottles installs and runs its bundle
  (idea only, GPL-3, no code copied).
- **Runners:** public repos get 4 vCPU, 16 GB RAM, ~14 GB+ free disk, 6 h max; image 2.8 GB + build 1.1 GB fit.
- **Unverified, checked by running CI:** GHCR package visibility for fork PRs (fallback: build on a miss);
  bwrap on Ubuntu 24.04 runners (AppArmor user namespaces; fallback `sysctl`); cold build times
  (est. qa 30–45 min, Flatpak 40–70 min).
- **New gaps:** none.

## Scope
- `.github/workflows/ci.yml`: jobs `qa`, `flatpak`, `flatpak-matrix` on pull requests and pushes to `main`;
  `concurrency` cancels superseded runs; `timeout-minutes` per job; `permissions` least-privilege
  (`packages: write` only where the image is pushed, on `main`).
- `redux/dev.sh`: `REDUX_CCACHE_DIR` (host dir instead of the named volume) and a `REDUX_IMAGE` override.
- QA report counts `l8.flatpak-matrix` from CI; docs and credits.
