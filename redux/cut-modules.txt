# VLC plugins Redux Video Player does not build (D14, D20). The machine-readable twin of the "Cut" list in
# redux/SCOPE.md. redux/tools/build.sh passes these names to meson (-Dredux_cut_modules), and modules/meson.build
# marks them `enabled: false`, so they aren't compiled and tests that need them are skipped.
# One plugin name per line (the name in its meson.build, i.e. lib<name>_plugin.so); `#` starts a comment.
# Bringing a plugin back: delete its line, add a DECISIONS.md entry, run `build.sh reconfigure`.
# Kept on purpose although close to a cut feature: decoders for subtitle and audio formats found inside files
# (zvbi teletext, aribsub, scte27, cc, fluidsynth, gme, sid, mod), file_logger ("Save a log"), and the test helpers.
